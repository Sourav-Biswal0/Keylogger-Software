## 📌 About The Project

**Keylogger Simulation** is a cybersecurity mini project built using **Python** and **HTML/CSS** to demonstrate how keyboard activity tracking works in a secure and educational way.

The project captures typed input, records timestamps, calculates typing speed, displays frequently used keys, and provides a modern web-based UI for user interaction.

This project is designed for **learning cybersecurity concepts**, **Python programming**, and **frontend integration**.

---

## ✨ Features

✅ Real-time keyboard input simulation  
✅ Records every typed key with timestamp  
✅ Calculates typing speed (Keys Per Minute)  
✅ Shows most frequently used keys  
✅ Saves output to text file automatically  
✅ Clean and attractive HTML/CSS interface  
✅ Download report option  
✅ Beginner-friendly cybersecurity project
